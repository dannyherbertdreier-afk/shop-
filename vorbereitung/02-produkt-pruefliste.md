# 2 · Produkt-Prüfliste

So wird jedes Produkt geprüft, bevor es in den Shop kommt – egal ob Dropshipping (z. B. CJdropshipping)
oder Print on Demand (z. B. Printful/Printify).

**Ablauf:** CEO schickt Link oder Screenshot → Prüfung nach dieser Liste → Ergebnis „Aufnehmen“,
„Nachfragen“ oder „Ablehnen“ → bei „Aufnehmen“: Muster bestellen.

---

## A · K.-o.-Kriterien (ein „Nein“ = Ablehnen)

| # | Kriterium | Prüfen wo |
|---|---|---|
| A1 | Einkaufspreis inkl. Versand zum Kunden zwischen **5 und 50 €** | Lieferanten-Konto |
| A2 | Versand **aus einem EU-Lager** (bzw. Produktion in der EU bei Print on Demand) | Produktseite → Lagerort / Druckpartner |
| A3 | Produktfotos **ohne fremde Marken-Logos** und mit Nutzungserlaubnis für den Shop | Fotos vergrößert prüfen; Nutzungsbedingungen des Lieferanten |
| A4 | **Hersteller- bzw. Verantwortlichen-Angaben** (Name, Anschrift, Kontakt) verfügbar – Pflicht nach GPSR | Produktseite / Anfrage an Lieferant |
| A5 | Keine Fälschung, kein Nachbau einer Marke | Optik, Name, Logo prüfen |
| A6 | Rechnerischer Gewinn **nicht negativ** | `gewinnrechner.xlsx` |

## B · Qualität und Angaben (beeinflusst die Bewertung)

| # | Kriterium | Gut | Schlecht |
|---|---|---|---|
| B1 | Lieferzeit zum Kunden in Deutschland | bis 7 Werktage | über 14 Werktage |
| B2 | Materialangabe (Faserzusammensetzung bei Textilien) | vollständig angegeben | fehlt |
| B3 | Größentabelle in cm (Rücken, Brust, Hals) | vorhanden | nur „S/M/L“ |
| B4 | Bewertungen / Verkaufszahlen beim Lieferanten | viele, überwiegend gut | keine / schlecht |
| B5 | Varianten (Farben/Größen) | sinnvolle Auswahl XS–XL | nur eine Größe |
| B6 | Sicherheitshinweise (z. B. Kleinteile, Batterien bei LED-Artikeln) | vorhanden, verständlich | fehlen |
| B7 | Branding möglich (Packzettel, Etikett, Verpackung) | ja | nein |
| B8 | Rückgabe-/Reklamationsregeln des Lieferanten | klar geregelt | unklar |
| B9 | Marge laut Gewinnrechner | „ok“ (ab 15 %) | „knapp“ |

## C · Besondere Pflichten je Produktart (prüfen lassen)

| Produktart | Zusätzlich klären |
|---|---|
| Textilien (Mäntel, Pullover, Overalls) | Pflicht zur Faserangabe – gilt sie für Tierbekleidung? (nicht geklärt, rechtlich prüfen) |
| LED-Leuchtanhänger, alles mit Batterie | Batterie-Registrierung (Stiftung EAR), Entsorgungshinweise |
| Pflegeprodukte (z. B. Pfotenbalsam) | Kein Heilversprechen; Inhaltsstoffe; ggf. weitere Vorschriften – rechtlich prüfen |
| Print-on-Demand-Motive | Eigene oder lizenzierte Motive, keine fremden Marken, Figuren oder geschützten Sprüche |

```
A3 Fotos ok               ☐ ja  ☐ nein
A4 Herstellerangaben      ☐ ja  ☐ nein
A5 kein Markennachbau     ☐ ja  ☐ nein
A6 Gewinn ≥ 0             ☐ ja  ☐ nein

B1–B9 Punkte (je 0 = schlecht, 1 = mittel, 2 = gut):  ___ / 18

Ergebnis:  ☐ Aufnehmen (alle A = ja, B ≥ 12)
           ☐ Nachfragen (alle A = ja, B 8–11 oder Angaben fehlen)
           ☐ Ablehnen (ein A = nein oder B < 8)

```

Die Punktgrenzen (12 / 8) sind ein Vorschlag, keine feste Regel – nach den ersten Produkten anpassen.

(Passform, Nähte, Geruch, Verpackung, Lieferzeit).
